# Zerobrick

Zerobrick is organized into separate directories for its schema, builder,
parser, API, web interface, and application code.

## Project structure

- `schema/` — schema definitions
- `builder/` — builder implementation
- `parser/` — parser implementation
- `api/` — API code
- `web/` — web interface
- `app/` — application code
- `out/` — generated output

## Development

This repository is currently a project scaffold. Add setup and run instructions
here as the implementation and its tooling are established.
